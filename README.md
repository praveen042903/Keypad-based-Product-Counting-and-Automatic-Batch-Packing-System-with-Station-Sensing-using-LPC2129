# Keypad-based-Product-Counting-and-Automatic-Batch-Packing-System-with-Station-Sensing-using-LPC2129
The Keypad Based Product Counting and Automatic Batch Packing System with Station Sensing using LPC2129 is an embedded systems project designed to automate industrial product counting and batch packing. The LPC2129 ARM7 microcontroller controls the entire operation. A keypad allows the operator to set the required batch quantity, while IR sensors detect and count products moving along the conveyor. The current count is displayed on an LCD. Once the preset quantity is reached, the controller automatically stops the motor and initiates the batch packing process. Station sensing ensures accurate product detection and positioning. LEDs and a buzzer provide status indications and alerts. This system reduces manual effort, minimizes counting errors, improves packing accuracy, and increases productivity in industrial applications.
