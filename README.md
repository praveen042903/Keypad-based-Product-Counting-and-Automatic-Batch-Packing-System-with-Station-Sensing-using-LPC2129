# Keypad-based-Product-Counting-and-Automatic-Batch-Packing-System-with-Station-Sensing-using-LPC2129
The Keypad Based Product Counting and Automatic Batch Packing System using LPC2129 automates industrial packing. A keypad sets batch quantity, while IR sensors detect and count products. The microcontroller displays the count on an LCD and controls the motor for accurate batch packing.
